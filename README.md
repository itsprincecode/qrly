# QRly

A modern and customizable QR code generator built with React.

Generate QR codes for websites, social media profiles, and custom links. Customize the appearance and download your QR code instantly.
<img width="1256" height="963" alt="image" src="https://github.com/user-attachments/assets/7e4223e7-43d1-4140-8895-bc234a9b64c7" />

## ✨ Features

- Generate QR codes instantly
- Website and social media presets
- Instagram, YouTube, LinkedIn, GitHub, WhatsApp, Telegram, and more
- Custom QR colors
- QR size and margin customization
- Error correction settings
- Optional logo support
- Download QR codes as PNG
- Download QR codes as SVG
- Live QR preview
- Responsive design
- Smooth animations and transitions
- Supabase integration for storing QR configurations
- Modern minimalist UI

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Supabase
- QR Code Library
- Lucide React
